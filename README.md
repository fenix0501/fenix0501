### Projects

#### 🐊 [Prompt Radar](https://github.com/fenix0501/nuclear_it_hack_croc_solved)

A local analytics system for AI-agent conversations. It clusters dialogue scenarios with RuBERT embeddings, estimates task success and business value, analyzes costs, and presents the results in an interactive dashboard.

`Python` `PyTorch` `RuBERT` `K-Means` `React`

#### 🎬 [Shorts Maker](https://github.com/fenix0501/shorts_maker)

A cross-platform desktop app that finds promising moments in long videos and exports vertical 9:16 clips for Shorts, Reels, and TikTok. Speech recognition and processing run locally with faster-whisper and FFmpeg.

`Python` `faster-whisper` `FFmpeg` `Desktop`

#### 🏋️ [Gym Powerlifting Assistant](https://github.com/fenix0501/Gym-Powerlifting-Assistant)

An ML-powered assistant that predicts powerlifting performance from athlete characteristics and recommends suitable weights for squats, bench press, and deadlifts.

`Python` `Machine Learning` `Jupyter`
